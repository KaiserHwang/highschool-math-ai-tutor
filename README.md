# MathPulse 고1 수학 연습장

2022 개정 교육과정 **공통수학1·2**를 위한 수준 진단, 단원별 3단계 힌트 코칭, 오답 복습 웹앱입니다.
설치 없이 브라우저에서 열고, 태블릿에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

**바로 쓰기:** https://kaiserhwang.github.io/highschool-math-ai-tutor/

## 무엇을 하나요

| 기능 | 내용 |
|---|---|
| 수준 진단 12문제 | 정답 여부와 함께 **확신도**(확실/헷갈림/찍음), **힌트 사용**, **풀이 시간**을 반영해 다섯 가지 역량(연산·식 변형, 개념·원리, 조건 해석·추론, 그래프·도형 감각, 발상·심화)과 단원별 준비도를 계산합니다. 확신했는데 틀린 문제는 개념 오해로 따로 표시합니다. |
| 학습 트랙 | 진단 결과로 개념 완성 / 내신 1등급 / 최상위 도전 중 하나를 추천하고, 추천 문제의 난이도를 맞춥니다. 직접 바꿀 수도 있습니다. |
| 문제 은행 70문제 | 7개 단원 × 기본·내신 필수·심화·최상위, 그리고 선행 학습자용 단원 융합 문제. 모든 문제에 개념 정리, 2단계 힌트, 완전 풀이, 함정 설명이 있습니다. |
| 3단계 힌트 코칭 | ① 조건을 식으로 번역 → ② 결정적인 식 세우기 → ③ 풀이 전체. 앞 단계를 열어야 다음 단계가 열립니다. 힌트를 쓴 만큼 숙련도 점수에 반영됩니다. |
| 디지털 연습장 | 모눈 위에 펜·손가락·마우스로 필기. 애플펜슬·S펜을 쓰면 손바닥 터치는 무시합니다. 그림으로 저장해 AI에게 사진으로 보여줄 수 있습니다. |
| 오답 복습 | 틀렸거나 풀이를 보고 푼 문제는 자동으로 오답노트에 들어갑니다. 원인(개념 미숙/조건 누락/발상 막힘/계산 실수)을 고르고, 1일 → 3일 → 7일 → 14일 간격으로 다시 풉니다. 힌트 없이 네 번 통과하면 졸업합니다. |
| 구독 AI 연결 | Claude, ChatGPT, Gemini 구독 계정으로 질문합니다(API 키 불필요). 문제, 내가 낸 답, 이미 본 힌트, 풀이 메모를 담아 "정답을 바로 말하지 말고 다음 한 걸음만 짚어 달라"는 지침과 함께 보냅니다. |
| 학습 리포트 | 최근 7일·4주 학습량, 첫 시도 정답률, 힌트 사용률, 역량 변화(진단 대비 현재), 단원별 숙련도, 오답 원인 분포. 인쇄하거나 PDF로 저장할 수 있고, AI에게 보내 다음 주 학습 계획을 받을 수 있습니다. |

## 사용 순서

1. **수준 진단**을 먼저 봅니다(약 25분). 모르는 문제는 건너뛰는 편이 진단에 도움이 됩니다.
2. **오늘** 화면의 "다음 문제"를 풉니다. 숙련도가 낮은 단원, 트랙에 맞는 난이도 순으로 추천됩니다.
3. 막히면 힌트를 한 단계씩 엽니다. 그래도 모르겠으면 풀이 메모를 적고 **AI에게 묻기**를 누릅니다.
4. **오답 복습**에 빨간 숫자가 뜨면 그날 복습할 문제가 있다는 뜻입니다.
5. 보호자는 **리포트**에서 학습 현황을 확인합니다.

### 구독 AI 연결 방법

- **Claude, ChatGPT**: 버튼을 누르면 질문이 입력창에 채워진 상태로 새 창이 열립니다.
- **Gemini**: 질문이 클립보드에 복사되고 Gemini가 열립니다. 입력창에 붙여넣으세요.
- **전용 튜터 방(선택)**: 설정 → "튜터 지침 복사"로 지침을 복사해 Claude 프로젝트, ChatGPT GPT, Gemini Gem을 만들고 그 주소를 설정에 넣으면, 버튼이 그 방을 엽니다(질문은 클립보드로 전달).

각 서비스의 로그인은 그 서비스에서 평소처럼 합니다. 이 앱은 계정 정보나 API 키를 다루지 않으므로, 다른 사람이 주소로 들어와도 보호자의 AI 구독을 쓸 수 없습니다.

## 기록은 어디에 저장되나요

모든 기록은 **이 기기의 브라우저(localStorage)에만** 저장되고 서버로 보내지 않습니다. 다른 사람이 같은 주소로 접속해도 아드님의 기록은 보이지 않습니다.
브라우저 데이터를 지우면 기록도 사라지므로, 설정 → **백업 파일 내려받기**로 가끔 백업하세요. 다른 기기로 옮길 때도 백업 파일을 불러오면 됩니다.

## 문제의 정확성

모든 문항의 정답은 `tests/verify_answers.py`에서 **풀이와 다른 방법(전수 조사, 기호 계산)으로 다시 계산해** 데이터와 대조합니다. 객관식은 정답 보기가 계산값과 같은지, 다른 보기와 값이 겹치지 않는지도 확인합니다. 문제를 추가하거나 고치면 이 검사를 함께 갱신하세요.

교육과정 범위는 2022 개정 수학과 교육과정의 공통수학1(다항식, 방정식과 부등식, 경우의 수, 행렬)과 공통수학2(도형의 방정식, 집합과 명제, 함수와 그래프) 성취기준을 따릅니다. 외분점처럼 공통수학에서 빠진 내용은 다루지 않고, 행렬은 2×2 이하의 연산까지만 다룹니다.

## 구조

```
index.html                  앱 뼈대
assets/css/app.css          화면 디자인(밝게/어둡게, 인쇄)
assets/js/app.js            화면 전환(#/ 주소)
assets/js/store.js          기록 저장·백업
assets/js/model.js          채점, 숙련도, 역량, 추천, 복습 주기
assets/js/content/          단원 개념, 문제 은행, 진단 문항
assets/js/views/            오늘, 진단, 단원, 문제, 오답, 리포트, 설정
assets/js/lib/              수식 렌더링, 레이더 차트, 연습장, AI 연결
assets/vendor/katex/        수식 렌더러(KaTeX 0.16, 오프라인용 내장)
sw.js, manifest.webmanifest 오프라인 사용과 홈 화면 추가
tests/                      정답 검증, 콘텐츠 검사, 브라우저 종단 테스트
docs/SERVICE_PLAN.md        기획 문서
```

빌드 단계가 없는 정적 사이트입니다. GitHub Pages의 `main` 브랜치 루트를 그대로 배포합니다.

## 개발

```bash
python3 -m http.server 8080        # http://localhost:8080 에서 실행
pip install sympy && python3 tests/verify_answers.py   # 정답 검증
node tests/content-check.mjs       # 수식·HTML·캐시 목록 검사
npm i --no-save playwright && npx playwright install chromium
node tests/e2e.mjs                 # 브라우저 종단 테스트(서버 실행 중일 때)
```

파일을 추가하거나 지우면 `sw.js`의 `ASSETS` 목록과 `VERSION`을 갱신하세요. `content-check.mjs`가 목록이 맞는지 검사합니다. GitHub Actions(`.github/workflows/check.yml`)가 푸시할 때마다 세 가지 검사를 실행합니다.
