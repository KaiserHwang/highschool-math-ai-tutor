# MathPulse 고1 수학 개념 학습

2022 개정 교육과정 **고1 공통수학1·2**의 **개념 이해에 특화한** 웹앱입니다. 문제를 많이 푸는 것은 시중 문제집에 맡기고, 이 앱은 개념을 직접 움직여 이해하고(예측·탐구·유도), 답과 함께 **그렇게 고른 이유**를 물어 잘못 이해한 부분을 짚고(개념 질문·오답별 설명), 막히면 앞 개념을 거꾸로 따라가 약한 곳을 찾고(개념 지도·선수 개념 역추적), 배운 개념을 잊지 않게 1주·3주·2개월 간격으로 다시 확인하는 데 집중합니다. 인강이나 문제집과 함께 쓰는 보조 교재로 설계했습니다.

> **학습 범위**: 지금은 고1 공통수학1·2만 다룹니다. 교육부 안내에 따르면 2028학년도 이후 수능 수학은 대수, 미적분Ⅰ, 확률과 통계에서 출제되며, 이 앱은 그 앞 단계의 기초를 다집니다. 단원 화면마다 "이 단원이 이어지는 곳"으로 후속 과목과의 연결을 안내합니다. 후속 과목은 이후에 단계적으로 추가할 계획입니다.
설치 없이 브라우저에서 열고, 태블릿에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 사용 순서

0. 처음에는 **수준 진단**을 봅니다(17문제, 약 35분). 모르는 문제는 건너뛰는 편이 진단에 도움이 됩니다.
1. 매일 **오늘** 화면 맨 위의 **오늘의 개념 확인**부터 합니다(약 6분).
2. 처음 배우거나 헷갈리는 단원은 **개념 학습**에서 소단원을 공부합니다. 결과를 먼저 예측하고 그래프를 움직여 확인한 뒤, 예제를 혼자 풀고 풀이를 한 단계씩 열어 비교합니다. 확인 문제를 풀고, 여유가 있으면 "한 걸음 더"의 심화 예제와 문제까지 풉니다. 마지막으로 핵심을 내 말로 설명해 보고 "이해했어요"를 누릅니다.
3. 개념을 익혔으면 **오늘** 화면의 "개념 적용 문제"를 풉니다. 유형 반복 연습은 쓰고 있는 문제집으로 하세요. 풀던 단원을 이어서, 다 끝나면 숙련도가 낮은 단원을 트랙에 맞는 난이도로 추천합니다.
4. 단원을 어느 정도 공부했으면 **단원 → 배운 범위 혼합 평가**로 처음 보는 문제를 단원 이름 없이 풀어 봅니다.
5. 막히면 힌트를 열기 전에 "개념" 링크로 관련 소단원을 다시 보고, 그래도 막히면 힌트를 한 단계씩 엽니다. 그래도 모르겠으면 풀이 메모를 적고 **AI에게 묻기**를 누릅니다.
6. **복습**에 빨간 숫자가 뜨면 그날 복습할 문제나 다시 확인할 개념이 있다는 뜻입니다.
7. 보호자는 **리포트**에서 학습 현황을 확인합니다.

### 구독 AI 연결 방법

- **Claude, ChatGPT**: 버튼을 누르면 질문이 입력창에 채워진 상태로 새 창이 열립니다.
- **Gemini**: 질문이 클립보드에 복사되고 Gemini가 열립니다. 입력창에 붙여넣으세요.
- **전용 튜터 방(선택)**: 설정 → "튜터 지침 복사"로 지침을 복사해 Claude 프로젝트, ChatGPT GPT, Gemini Gem을 만들고 그 주소를 설정에 넣으면, 버튼이 그 방을 엽니다(질문은 클립보드로 전달).

각 서비스의 로그인은 그 서비스에서 평소처럼 합니다. 이 앱은 계정 정보나 API 키를 다루지 않으므로, 다른 사람이 주소로 들어와도 보호자의 AI 구독을 쓸 수 없습니다.

## 기록은 어디에 저장되나요

모든 기록은 **이 기기의 브라우저(localStorage)에만** 저장되고 서버로 보내지 않습니다. 다른 사람이 같은 주소로 접속해도 아드님의 기록은 보이지 않습니다.
브라우저 데이터를 지우면 기록도 사라지므로, 설정 → **백업 파일 내려받기**로 가끔 백업하세요. 다른 기기로 옮길 때도 백업 파일을 불러오면 됩니다. 백업 파일은 전체 구조를 검사한 뒤에만 반영하고, 형식이 맞지 않으면 기존 기록을 그대로 둡니다.

## 문제의 정확성

모든 문항의 정답은 `tests/verify_answers.py`, `tests/verify_extra.py`, `tests/verify_ladder.py`에서 **풀이와 다른 방법(전수 조사, 기호 계산, 수치 최적화)으로 다시 계산해** 데이터와 대조합니다. 객관식은 정답 보기가 계산값과 같은지, 다른 보기와 값이 겹치지 않는지도 확인합니다. 그림 문제는 그림 데이터(포물선의 계수, 점의 좌표, 도로망의 끊긴 길, 벤 다이어그램의 색칠한 영역)를 직접 읽어 정답을 계산하므로, 그림과 정답이 어긋나면 검사가 실패합니다.

개념 학습은 `tests/verify_lessons.py`가 세 가지를 검사합니다.

- 확인 문제 전부와, 답이 하나의 값으로 정해지는 예제의 정답을 다른 방법(전수 조사, 기호 계산)으로 다시 계산합니다.
- 답이 범위인 예제(예: $-1<k<3$)는 매개변수를 촘촘히 바꿔 가며 경계 안팎을 직접 확인합니다.
- 예측 문제의 정답 보기, 심화 예제와 심화 확인 문제의 답도 `tests/verify_plus.py`에서 따로 계산합니다(전수 조사, 기호 계산, 경계 근처 촘촘한 대입).
- 개념 질문 176개 중 답이 계산으로 정해지는 110개는 정답 보기를 다른 방법으로 다시 계산합니다. 나머지 66개(정의·포함 관계·그래프 읽기를 묻는 문항)와 모든 이유 보기는 계산으로 검증할 수 없어 사람이 검토했습니다. 이유 보기가 정확히 4개인지, 정답 이유에는 오개념이 붙지 않고 틀린 이유마다 정해진 오개념 분류가 붙었는지, 보기·이유가 겹치지 않는지는 `content-check.mjs`가 확인합니다.
- 핵심 정리에 적은 공식의 **적용 조건**을 정례와 반례로 확인합니다. 무리함수 역함수의 정의역, 유리함수 점근선 공식의 조건($c\ne0$, $ad-bc\ne0$), 완전제곱식과 $D=0$, 코시-슈바르츠 부등식의 등호 조건, 켤레근의 전제, 원 밖의 점에서 그은 접선, 두 직선의 평행 조건, 두 원의 위치 관계가 대상입니다.

`content-check.mjs`는 모든 소단원이 예측·탐구·유도·심화·설명 과제와 확인 문제별 오답 설명을 갖추었는지, 탐구 그래프가 슬라이더의 모든 값에서 오류 없이 그려지는지, "찾아보기" 과제마다 도달할 수 있는 값이 있고 처음 상태에서는 아직 달성되지 않았는지, 오답 설명이 정답에 붙지 않았는지, 선수 관계가 앞 소단원만 가리키는지(순환 없음), 모든 문제가 소단원과 연결되어 있는지, 소단원마다 관련 문제가 2개 이상이고 기본 문제부터 시작하는지, 학습용 문항과 문제 은행·진단 사이에 사실상 같은 문항이 없는지, 진단이 단원마다 2문항 이상인지를 확인합니다. 소단원별 연습·평가 범위는 [docs/COVERAGE.md](docs/COVERAGE.md)에 정리되어 있습니다(`node tools/coverage.mjs`로 생성).

비슷한 문제 생성기는 `tests/gen-check.mjs`가 유형마다 500문제씩 만들어 생성기와 다른 방법으로 정답을 다시 구하고, 수식 표기와 보기를 점검합니다. 문제를 추가하거나 고치면 이 검사들을 함께 갱신하세요.

교육과정 범위는 2022 개정 수학과 교육과정의 공통수학1(다항식, 방정식과 부등식, 경우의 수, 행렬)과 공통수학2(도형의 방정식, 집합과 명제, 함수와 그래프) 성취기준을 따릅니다. 외분점처럼 공통수학에서 빠진 내용은 다루지 않고, 행렬은 2×2 이하의 연산까지만 다룹니다.

빌드 단계가 없는 정적 사이트입니다. GitHub Pages의 `main` 브랜치 루트를 그대로 배포합니다.

## 개발

```bash
python3 -m http.server 8080        # http://localhost:8080 에서 실행
pip install sympy && python3 tests/verify_answers.py   # 정답 검증
python3 tests/verify_lessons.py    # 개념 학습 예제·확인 문제·예측·심화 정답, 핵심 정리의 적용 조건 검증
node tools/coverage.mjs            # 학습·평가 범위 표(docs/COVERAGE.md) 갱신
node tests/gen-check.mjs           # 비슷한 문제 생성기 검사
node tests/content-check.mjs       # 수식·HTML·그림 설명·서비스 워커 검사
node tests/unit.mjs                # 회귀 검사(백업, 캐시 정리, 시간대별 통계, 간격 복습, 숙련도, 진단 준비도, 개념 재확인, 심화 기록, 개념 간격 복습, 개념 질문 채점·기록·오개념 통계, 선수 관계·역추적·약한 개념)
node tools/gen-sw.mjs              # 파일을 고친 뒤 서비스 워커 갱신
npm i --no-save playwright && npx playwright install chromium
node tests/e2e.mjs                 # 브라우저 종단 테스트(서버 실행 중일 때)
```

파일을 고치면 `node tools/coverage.mjs`와 `node tools/gen-sw.mjs`를 실행하세요. 버전이 파일 내용의 해시로 정해지므로, 배포하면 사용자의 오프라인 캐시도 자동으로 새 버전으로 바뀝니다. `content-check.mjs`가 최신인지 검사합니다. 그림을 고칠 때는 `tests/gallery.html`에서 모든 그림을 한눈에 볼 수 있습니다. GitHub Actions(`.github/workflows/check.yml`)가 푸시할 때마다 여섯 가지 검사를 실행합니다.
