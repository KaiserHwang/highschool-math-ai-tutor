# MathPulse 기획 문서

## 목표

공통수학1 이상을 선행 중인 예비 고1 학생이 **개념을 정확히 이해하고, 처음 보는 심화 문제에서 첫 식을 스스로 세우는 힘**을 기르도록 돕는다. 보호자는 학습 현황을 한눈에 확인한다.

## 제품 방향: 개념 특화 보조 교재

문제 수와 강의 전달력은 시중 문제집·인강을 따라가지 않는다. 대신 종이책과 영상이 구조적으로 못 하는 것에 집중한다.

- **직접 해 보며 이해**: 예측 → 탐구 그래프 → 유도 따라가기로 개념을 스스로 다시 만든다.
- **오개념 교정**: 개념 질문으로 답과 함께 "그렇게 고른 이유"를 묻고, 틀린 이유마다 연결된 오개념을 짚는다. 확인 문제의 예상 오답마다 그 답이 나온 생각도 보여 준다.
- **막힌 곳의 뿌리 찾기**: 개념 지도로 소단원 사이의 선수 관계를 보여 주고, 막힌 개념에서 앞 개념을 거꾸로 확인해 약한 곳부터 다시 보게 한다.
- **잊지 않게 관리**: 배운 개념을 1주 → 3주 → 2개월 간격으로 짧게 다시 확인한다(오늘의 개념 확인). 매일 앱을 여는 이유가 된다.

문제 은행, 혼합 평가, 오답 복습은 유지하되 "개념 적용 확인" 역할로 둔다. 유형 반복 연습은 학생이 쓰는 문제집에 맡긴다.

### 다음 단계

1. (완료) 개념 간격 복습과 오늘 화면 개편
2. (완료) 개념 질문 문항: 소단원마다 "답 + 그렇게 고른 이유"를 묻는 문항 4개(총 176개). 틀린 이유마다 오개념을 연결해 개념 확인에 섞는다.
3. (완료) 개념 지도와 선수 개념 역추적: 막히면 앞 개념 중 약한 곳을 찾아 짧게 확인한다.

## 개념 간격 복습

- 대상: 이해 표시를 했거나 기본 확인 문제를 모두 맞힌 소단원. 배운 날로부터 1주 뒤 첫 확인.
- 문항: 개념마다 2문항. 같은 유형의 비슷한 문제 생성기가 있으면 처음 보는 숫자 문제 1개 + 개념 질문 1개, 없으면 개념 질문 2개. 개념 질문은 소단원 화면에서 보지 않은 3·4번부터 내고 복습할 때마다 돌린다. 첫 답으로 채점하고, 개념 질문은 답과 이유가 모두 맞아야 통과한다.
- 두 문항을 모두 맞히면 다음 간격(1주 → 3주 → 2개월), 세 번 통과하면 "오래 기억함". 하나라도 틀리면 1주 단계로 돌아가고 다음 날 처음 보는 문제로 재확인을 예약한다. 재확인이 남아 있는 동안은 간격 복습에 올리지 않는다.
- 오답노트와 같은 규칙: 예정일 전 성공은 연습으로만 보고, 하루에 한 번만 반영한다.
- 오늘 화면 맨 위에 하루 3개(약 6분)씩. 다 하면 남은 것을 이어서 할 수 있다.

## 개념 질문

- 소단원마다 4문항. 문항마다 답 보기(2~5개)와 이유 보기(4개)가 있고, 둘 다 맞아야 정답이다.
- 틀린 이유마다 오개념 분류 하나를 붙인다(12종): 조건 빠뜨림, 경계·등호 혼동, 부호·방향 혼동, 예 몇 개로 일반화, 방향 혼동(역·필요충분), 비슷한 공식 혼동, 범위 무시, 중복·순서 세기 혼동, 정의 오해, 수의 성질을 그대로 옮김, 방법 선택 착오, 그래프 해석 오류. 이름과 설명은 `assets/js/content/misconceptions.js`에 있다.
- 채점은 네 가지로 나눈다: 둘 다 맞음 / 답만 맞음(운으로 맞힘) / 이유만 맞음(적용 실수) / 둘 다 틀림. 이유가 틀렸으면 오개념 이름과 설명, 맞는 답·이유, 짧은 해설을 보여 준다.
- 기록은 문항마다 최근 12번(날짜, 고른 답, 고른 이유). 리포트는 최근 60일의 틀린 이유를 오개념별로 세어 보여 주고, AI 요약에도 넣는다.
- 정답이 늘 같은 자리에 있지 않도록 보기와 이유의 순서를 문항 id로 정한 순서로 섞는다(매번 같은 순서라 기록과 화면이 어긋나지 않는다).

## 개념 지도와 선수 개념 역추적

- 선수 관계: 소단원마다 "먼저 알아야 할 소단원"(`pre`)을 둔다. 교육과정 순서상 앞 소단원만 가리키고(순환 없음, content-check가 확인), 단원을 넘는 관계도 넣는다(예: 인수분해 → 삼차방정식, 판별식 → 원과 직선, 집합 → 함수, 대칭이동 → 역함수, 평행이동 → 유리·무리함수, 절대부등식 → 치환).
- 지도: 단원이 열, 소단원이 위에서 아래로 놓이고 화살표는 앞 개념 → 뒤 개념. 넓은 화면은 네 단원씩, 좁은 화면은 두 단원씩 띠로 묶는다. 개념을 누르면 앞 개념 전체(파랑)와 바로 뒤 개념(주황)을 강조하고, 넓은 화면은 옆에, 좁은 화면은 아래에서 올라오는 카드로 자세히 보여 준다.
- 다시 볼 개념: 재확인이 남았거나, 최근 60일 개념 질문 중 마지막 풀이가 틀린 문항이 있는 개념. 다시 맞히면 빠진다. "먼저 다지면 좋은 개념"은 이 중 그 위에 쌓이는 개념(직간접 뒤 개념)이 많은 순.
- 역추적: 바로 앞 개념부터 개념마다 개념 질문 하나(아직 안 푼 것 → 오래전에 푼 것, 오늘 맞힌 것은 뒤로). 틀리면 그 개념의 앞 개념을 대기열 맨 앞에 넣어 먼저 묻는다(깊이 우선). 최대 6문항. 결과는 틀린 앞 개념을 교육과정 순서로 나열하고, 그중 더 앞 개념은 괜찮거나 없는 것을 "여기부터"로 표시한다. 모두 맞히면 막힌 개념 자체를 다시 보라고 안내한다.
- 배운 개념(상태가 '아직'이 아님)을 역추적에서 틀리면 다음 날 재확인을 예약해 오늘 화면과 복습에 올린다. 아직 배우지 않은 개념은 예약하지 않고 그 소단원부터 공부하라고 안내한다. 풀이는 개념 질문 기록에 남아 오개념 통계에도 들어간다.

## 설계 원칙

1. **정답보다 사고 과정을 기록한다.** 진단은 확신도, 힌트 사용, 풀이 시간을 함께 본다. 찍어서 맞힌 문제는 낮게, 확신했는데 틀린 문제는 개념 오해로 따로 본다.
2. **해설을 한 번에 보여 주지 않는다.** 힌트는 조건 번역 → 결정적인 식 → 풀이 순서로만 열린다. 힌트를 쓴 만큼 숙련도 점수가 덜 오른다.
3. **틀린 문제는 다시 만난다.** 오답노트는 1·3·7·14일 간격 반복으로 운영하고, 힌트 없이 네 번 통과해야 졸업한다.
4. **AI는 과외 선생님처럼 쓴다.** 구독 중인 AI에 문제와 학생의 시도를 함께 보내되, 정답 대신 다음 한 걸음만 요청한다.
5. **문제의 정확성을 자동으로 검증한다.** 모든 정답은 독립 계산으로 대조한다.

## 역량 모델

| 역량 | 설명 |
|---|---|
| 연산·식 변형 | 곱셈공식, 인수분해, 복소수·행렬 계산 |
| 개념·원리 | 정의와 정리를 이해하고 알맞게 적용 |
| 조건 해석·추론 | 문장 조건을 식으로 번역하고 경우를 나눔 |
| 그래프·도형 감각 | 함수의 그래프와 좌표평면 도형 해석 |
| 발상·심화 | 처음 보는 문제의 결정적 첫 식 |

문항마다 역량 가중치를 매긴다. 진단 점수는 `난이도 가중치 × 역량 가중치 × 문항 점수`의 가중 평균이다.

- 진단 문항 점수: 정답일 때 확실 1.0, 헷갈림 0.75, 찍음 0.4. 힌트를 봤으면 ×0.7, 예상 시간의 2배를 넘기면 ×0.85. 오답은 0.
- 학습 문항 점수: 한 번에 1.0, 힌트 1단계 0.8, 2단계 0.6, 풀이를 보고 0.3. 첫 제출이 오답이었으면 ×0.85.
- 현재 역량 = 진단과 학습 기록의 가중 평균. 학습량이 쌓일수록 학습 기록의 비중이 커진다.
- 난이도 가중치: 기본 1, 내신 필수 2, 심화 3, 최상위 4.

## 개념 학습

단원마다 교과서의 소단원에 해당하는 개념 학습 44개를 둔다(Ⅰ 5, Ⅱ 11, Ⅲ 4, Ⅳ 4, Ⅴ 7, Ⅵ 6, Ⅶ 5, 융합 2). 각 소단원은 같은 순서로 읽힌다. 시중 개념서·인강이 "설명을 듣고 따라 푸는" 구조라면, 이 앱은 **학생이 먼저 생각하고 직접 움직여 본 뒤 설명과 맞춰 보는** 구조를 목표로 한다.

1. **먼저 생각해 보기**: 배우기 전에 결과를 예측하는 객관식 하나(예: "$x^4+4$는 인수분해될까?"). 틀린 예측이 곧 이번에 배울 내용이 되도록 설명을 붙인다. 이어서 **탐구 그래프**에서 슬라이더로 계수를 바꾸며 "찾아보기" 과제(예: 접하게 만들기, 해가 없게 만들기)를 해결한다. 과제는 학생이 직접 조건을 만들었을 때만 완료로 표시한다.
2. **핵심 정리**: 정의·공식을 상자로 정리하고, 필요한 곳에 그림을 넣는다.
3. **왜 그럴까**: 공식이 나오는 이유(유도, 그림, 반례)를 짧게 설명한다. "유도 따라가기"는 다음 줄을 먼저 생각해 보게 한 뒤 확인 버튼으로 연다. 외우기보다 다시 만들어 낼 수 있게 하는 것이 목표다.
4. **예제**: 풀이를 한 단계씩 열어 보며 자기 풀이와 비교한다.
5. **확인 문제**: 소단원마다 2~4개, 바로 채점한다. 예상되는 오답(부호 실수, 등호 누락, 공식 혼동)마다 "그 답이 나온 생각"을 짚어 준다. 숙련도에는 넣지 않고, 첫 시도 정오와 풀이 확인 여부로 "혼자 확인"을 판정한다.
6. **한 걸음 더(심화)**: 내신 심화·수능형으로 이어지는 발상 2~3개. 심화 예제에는 "어떻게 떠올리나"(발상 노트)를 붙이고, 심화 확인 문제 2개를 둔다. 심화 문제는 기록만 하고 "혼자 확인" 판정과 재확인 예약에는 넣지 않아 부담 없이 도전하게 한다.
7. **직접 설명해 보기**: 핵심 질문에 내 말로 답하고, 모범 설명과 핵심 요소 체크리스트로 스스로 점검하거나 AI에게 점검받는다. 쓴 설명은 기록에 남는다.
8. **내신 포인트·자주 하는 실수**
9. **관련 문제**: 이 개념을 쓰는 문제 은행 문제로 바로 간다. 문제 화면에서도 거꾸로 해당 개념으로 돌아올 수 있다. 소단원 머리에는 먼저 알아야 할 소단원을 표시한다.

학생이 "이해했어요"를 누르면 단원 목차와 오늘 화면에 표시된다. 추천 문제의 개념을 아직 보지 않았으면 오늘 화면이 "개념 먼저" 링크를 함께 보여 준다. 예제·확인 문제·예측·심화 문제의 정답은 `tests/verify_lessons.py`와 `tests/verify_plus.py`가 독립 계산으로 확인하고, 탐구 그래프는 `tests/content-check.mjs`가 슬라이더의 모든 값에서 그려 보며 과제마다 도달 가능한지 확인한다.

## 비슷한 문제 생성

자주 나오는 기본·필수 유형 19개는 숫자만 바꾼 문제를 만들어 낸다. 오답 복습에서 같은 문제를 반복하면 답을 기억해서 맞히게 되므로, 숫자를 바꾼 문제로 복습할 수 있게 했다. 생성된 문제는 숙련도에는 넣지 않고 연습 기록으로만 남긴다.

## 학습 근거와 평가(2026-10 보강)

- **처음 성과와 현재 숙련도를 나눈다.** 처음 풀었을 때의 성과는 그대로 두고, 현재 숙련도는 날짜 간격을 둔 복습 결과로 다시 계산한다. 간격 복습 단계는 예정일이 된 뒤 하루 한 번만 오른다.
- **자기 표시와 독립 확인을 나눈다.** "이해했어요"는 학생의 자기 표시이고, 확인 문제를 첫 시도에 풀이 없이 모두 맞히면 "혼자 확인"이다. 틀리거나 풀이를 본 개념은 다음 날 처음 보는 문제로 다시 확인한다.
- **진단은 출발점이다.** 단원마다 2~4문항이라 준비도는 중간값 쪽으로 보정하고 근거 문항 수를 함께 보인다. 그 단원 문제를 풀수록 추천은 실제 풀이 결과를 더 따른다.
- **학습용과 평가용을 나눈다.** 혼합 평가는 아직 풀지 않은 문제와 숫자를 바꾼 문제로만 내고, 단원 이름을 숨기며, 힌트와 정답은 제출 뒤에 공개한다. 학습용 문항과 은행·진단 사이의 중복은 자동 검사한다.
- 모든 점수는 이 앱의 공통수학 문제 기준 학습 지표이며 내신 등급이나 수능 점수로 환산하지 않는다.

## 학습 범위와 후속 과목

지금은 고1 공통수학1·2만 다룬다. 교육부 안내에 따르면 2028학년도 이후 수능 수학은 대수, 미적분Ⅰ, 확률과 통계에서 출제된다. 단원마다 이어지는 후속 과목을 안내하고, 후속 과목은 이후 단계적으로 추가한다. 추가할 때는 학년도별 출제 범위를 따로 관리하고(예: 미적분Ⅱ·기하는 2028 수능 출제 과목이 아님), 아직 배우지 않은 단원을 능력 부족으로 해석하지 않도록 이수 과목을 받는다.
